# Project Constitution

## Purpose

This document defines principles that apply across the project.

## Principles

### P-001 — Specification first
Approved specifications define project intent.

### P-002 — Explicit decisions
Important architectural and behavioral decisions must be documented.

### P-003 — Minimal change
Prefer the smallest safe change that satisfies the requirement.

### P-004 — Verification
Relevant behavior must be verified with tests and/or explicit validation.

### P-005 — Traceability
Important requirements should be traceable to tasks, implementation and tests.

### P-006 — Reproducibility
Builds, tests and development procedures should be reproducible.

### P-007 — Agent continuity
Project state must be recoverable from repository files without relying on conversation memory.
